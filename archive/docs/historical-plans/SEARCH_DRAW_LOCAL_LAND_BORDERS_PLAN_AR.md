# خطة رسم محيط الدولة المحلي من نتائج البحث

**الحالة:** منفّذة برمجياً — بانتظار قبول AE اليدوي فقط.  
**الهدف:** جعل زر الرسم الموجود في نتيجة البحث هو المسار الوحيد لإنشاء خريطة Vector عالية الدقة في After Effects، باستخدام بيانات محلية فقط وبمحيط الدولة الأرضي الكامل: حدود الدول المجاورة وخط الساحل الملاصق لليابسة، من دون EEZ أو حدود بحرية سياسية.

> **تحديث تدقيق المصدر — 2026-08-12:** عضو `ESH` في `countries_clipped.topojson` و`ESH` الافتراضي في Natural Earth يمثلان الشريط الضيق، وليس كامل الإقليم. لذلك يعيد مولّد البيانات تركيب كامل المنطقة جنوب `27°40′N` من التقسيمات المحلية، ثم يحفظ الناتج في حزمة التشغيل كمحيط مستقل واحد بهوية `ESH`. هذه معالجة بناء ثابتة؛ زر الرسم لا يستدعي `MAR` عند رسم الصحراء الغربية.

## 1. قرار المنتج المعتمد

```text
بحث عن بلد أو مدينة
        ↓
زر الرسم في النتيجة
        ↓
تحويل النتيجة إلى ISO_A3 للدولة الأم
        ↓
حزمة OpenGeo المحلية 10m
        ↓
الحلقات الخارجية لمضلع الدولة الأرضي
        ↓
طبقة AE: «اسم الدولة — COUNTRY OUTLINE»
```

### قواعد لا تقبل الاستثناء

- يرسم زر البحث محيط الدولة المغلق بلا Fill: الحدود الدولية وخط الساحل الذي يحد اليابسة.
- لا يستخدم زر البحث OSM أو `CloudBoundaryService` أو GeoJSON خارجي كبديل تلقائي.
- لا يدخل EEZ أو `Water Indicator` أو `Maritime` إلى نتيجة الرسم.
- زر `Vector Map` العام يُزال من الواجهة بعد انتقال زر البحث إلى المسار الجديد.
- الدولة الجزرية تُرسم كاملة بخط ساحلها؛ فلا تُعامل كحالة فارغة.

## 2. مواضع البيانات المحلية

الملفات المحلية الأصلية نُقلت كما هي إلى `scripts/vector-data-sources` لتكون **المصدر القانوني الوحيد للبناء**. عند كل بناء، يقرأ المحوّل المصدر 10m كاملاً، يسقط كل نقطة إلى Mercator بدقة `double` من دون حذف أو تقريب أو تبسيط، ثم يولّد ملف التشغيل. هذا ليس "مصدرًا خفيفًا بديلًا" ولا يخفض الجودة؛ إنه نفس الخطوط البرية عالية الدقة في صيغة وفهرس مناسبين لـ CEP وAE. لا تدخل الملفات الخام مباشرة إلى `client/assets` فقط كي لا تُشحن نسخ متعددة وغير مستخدمة.

```text
scripts/vector-data-sources/
├─ natural-earth/10m/                 # مصادر خام، لا تُشحن إلى CEP
│  ├─ ne_10m_admin_0_countries.geojson
│  ├─ ne_10m_admin_0_boundary_lines_land.geojson
│  └─ ne_10m_admin_0_boundary_lines_disputed_areas.geojson
└─ opengeo-profiles/
   └─ countries_clipped.topojson       # أساس طوبولوجي؛ يُطبّق عليه profile فصل MAR/ESH

client/assets/data/vectors/            # نواتج محسّنة محلية تُشحن مع الإضافة
├─ country-outlines-10m.json           # مصدر الرسم الفعلي: محيط الأرض + الساحل
├─ land-borders-10m.json               # فهرس خطوط الحدود الدولية، غير مستخدم في زر الرسم الحالي
├─ country-index-10m.json
└─ manifest.json                       # البصمة، سياسة الدقة، وتقرير التغطية
```

### سياسة المصدر والترخيص

- يحتفظ `SOURCES_MANIFEST.json` باسم المصدر، الدور، الحجم، SHA-256، والترخيص؛ ويحتفظ `client/assets/data/vectors/manifest.json` ببصمة مصدر التشغيل وسياسة الدقة وتقرير التغطية.
- ملفات `docs/bondaries explication` تبقى مرجعاً وتُنقل/تنسخ إلى مسار المصادر فقط أثناء مرحلة تنفيذ منظمة؛ لا تُحذف من `docs` تلقائياً.
- لا يدخل أي GeoJSON أو TopoJSON خام إلى `release/stage`.

## 3. عقد البيانات النهائي

مصدر الرسم الفعلي هو `country-outlines-10m.json`. يحتفظ بكل حلقة خارجية لمضلع أرض الدولة، أي بالحدود الدولية وخط الساحل، ويستبعد الثقوب الداخلية وEEZ:

```json
{
  "id": "outline-DZA-01",
  "type": "CountryLandOutline",
  "iso3": "DZA",
  "isClosed": true,
  "rings": [[ [x, y], [x, y] ]]
}
```

ويكون الفهرس مستقلاً وقابلاً للبحث المباشر:

```json
{
  "version": "1.0.0",
  "countries": {
    "DZA": { "outlineIds": ["outline-DZA-01"], "label": [x, y] },
    "MAR": { "outlineIds": ["outline-MAR-01"], "label": [x, y] }
  }
}
```

## 5. القرارات التي تحتاج اعتماداً قبل SDB-06

| القرار | الافتراضي المقترح |
|---|---|
| الدول الجزرية | ترسم كاملة بخط ساحلها المحلي |
| نتيجة مدينة | ترسم حدود الدولة الأم فقط |
| نتيجة ولاية/إقليم | لا ترسم حتى إضافة حزمة Admin 1 مستقلة |
| الحدود المتنازع عليها | معطلة افتراضياً وفي ملف منفصل |
| المغرب/الصحراء الغربية وفلسطين | بروفايلات محلية اختيارية، لا تُفرض ضمن `default` |
| اسم الطبقة | `Country — COUNTRY OUTLINE` |

## 6. المخاطر والضوابط

| الخطر | الضبط |
|---|---|
| ملف اسمه `land` يحوي عناصر مائية | تصفية حتمية بـ `TYPE === "Land"`، لا بالاسم فقط |
| خلط البحث والرسم | حدثا `search:selected` و`search:drawCountryOutline` منفصلان |
| تجمد CEP | لا Turf ولا union ولا parsing ثقيل وقت الضغط؛ كل المعالجة في build مسبق |
| اختلاف الصورة عن المسار | مصدر واحد محلي للحواف والتسميات والفهرس |
| حساسية الحدود السياسية | بروفايلات versioned ومراجعة صريحة وقابلة للرجوع |
