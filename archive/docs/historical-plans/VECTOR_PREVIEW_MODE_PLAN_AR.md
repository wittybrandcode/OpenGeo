# خطة وضع Vector Preview المحلي

**الإصدار:** 1.0  
**التاريخ:** 12 أغسطس 2026  
**الهدف:** تمكين المصمم من التنقل والتخطيط وإضافة الحركة بلا شبكة، من دون تغيير مصدر الصور أو مخرجات `Finalize`.

## العقد المعتمد

| وضع المعاينة | مصدر الرسم | طلبات الشبكة | Finalize |
|---|---|---|---|
| Satellite Preview | مزود البلاطات المختار | نعم عند الحاجة | يستخدم المصدر/الجودة المعتادين |
| Vector Preview | `world_mercator_boundaries.json` المضمّن | لا | لا يتغير |

الوضع المتجهي خاص بلوحة CEP؛ لا يرسل متجهات إلى AE ولا يبدل مزود الصور المخزن في Session.

## التنفيذ المنجز

- [x] زر `preview-mode-btn` في الشريط العلوي؛ حالته المرئية توضّح وضع Vector.
- [x] طبقة `VectorPreviewLayer` ترسم حدود 241 دولة من بيانات Mercator المحلية.
- [x] تبسيط مسارات تكيفي حسب الزوم، لمنع إرهاق CEF عند العالم الكامل.
- [x] تسميات دول انتقائية عند زوم مناسب وبحد أقصى 22 تسمية في الإطار.
- [x] إيقاف تنزيلات Preview المعلقة عند دخول الوضع المتجهي.
- [x] إعادة بناء قائمة تحميل البلاطات عند العودة إلى الوضع الصوري.
- [x] منع auto-preview الصوري وtrajectory raster preview أثناء الوضع المتجهي؛ تبقى Live Sync وFinalize منفصلين.

## تجربة الاستخدام

1. اضغط أيقونة الخريطة بجانب الإعدادات في الشريط العلوي.
2. تظهر خريطة حدود محلية مع رسالة `Offline Vector Preview — no tile downloads.`
3. التنقل، Zoom، البحث، العلامات، وKeyframes تعمل كالمعتاد.
4. اضغط الأيقونة نفسها للعودة إلى Satellite؛ تحمل الإضافة بلاطات الموقع الحالي فقط.

## حدود الإصدار الأول

- لا يوجد Auto fallback بعد فشل الشبكة بعد؛ التبديل يدوي ومقصود.
- Vector Preview لا يستبدل Finalize ولا يولد خريطة متجهية داخل AE.
- الأسماء باللغة الإنجليزية من dataset المضمّن؛ التعريب الكامل طبقة لاحقة مستقلة.

## القبول اليدوي

- [ ] افتح الإضافة مع اتصال ضعيف أو بعد تفعيل الوضع المتجهي: لا تظهر طلبات بلاطات ولا console errors.
- [ ] حرّك وزوّم 10 ثوانٍ: الحدود تبقى سلسة والأسماء لا تتكدس.
- [ ] عُد إلى Satellite: تظهر بلاطات الموقع الحالي ولا تعود أصول/طلبات قديمة بلا حاجة.
- [ ] نفّذ Finalize من وضع Vector: النتيجة تستخدم مزود الصور والجودة المختارين، لا الحدود المحلية.
