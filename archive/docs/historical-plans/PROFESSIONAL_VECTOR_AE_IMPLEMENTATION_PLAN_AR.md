# خطة تطوير الخرائط المتجهية الاحترافية داخل After Effects

**الحالة:** قيد التنفيذ — التنفيذ الآلي مكتمل، وقبول AE اليدوي فقط متبقٍ.  
**النطاق:** بيانات الحدود المحلية، معاينة Vector، ومُصدِّر Vector Map إلى After Effects.  
**خارج النطاق:** تغيير مسار `Finalize` الصوري أو إضافة أي طلب شبكة أثناء تشغيل الإضافة.

## النتيجة المعتمدة

يستخدم OpenGeo حزمة بيانات متجهية محلية موحّدة مبنية من Natural Earth (50m)، وتفصل العناصر التي يحتاجها المصمم:

```text
LAND       تعبئة الدول/اليابسة
BORDERS    الحدود الدولية البرية فقط
COAST      خط الساحل، اختياري ومعطل افتراضياً
LABELS     أسماء الدول، اختيارية بحسب المساحة المعروضة
```

لا تُضمّن حدود EEZ أو خطوط الـ 200 ميل البحري أو أي مؤشرات بحرية. يبقى مصدر البيانات الخام خارج حزمة الإصدار؛ أمّا الناتج المحوّل فقط فيُضمّن محلياً مع الإضافة.

## عقد البيانات والإخراج

| المجال | القرار |
|---|---|
| المصدر | Natural Earth Vector محلي؛ المعاينة العالمية 50m، وإخراج AE الافتراضي 10m من `Admin 0 Boundary Lines Land` |
| الإسقاط | Web Mercator داخل مساحة `262144 × 262144`، المطابقة لبلاطات OpenGeo |
| مستوى الجودة | AE: `High` افتراضي محلي 10m؛ حارس تعقيد يمنع تصدير نطاق أكبر من قدرة AE |
| توافق قديم | `world_mercator_boundaries.json` يبقى fallback؛ لا يُحذف |
| استبدال الطبقات | إعادة التصدير بنفس المنطقة/النمط تستبدل طبقاتها فقط؛ لا تحذف خرائط أخرى |
| شبكة وقت التشغيل | صفر في Vector Preview وVector Map المحلي |

## سياسة الجودة

- لا تُحوّل خريطة العالم كاملة بأقصى تفاصيل 10m تلقائياً؛ ذلك يضر أداء After Effects.
- يمكن لاحقاً إضافة `Ultra` إقليمي بدقة 10m بعد وضع حد واضح لعدد النقاط والمسارات.
- النزاعات السياسية تبقى قرار عرض منفصل؛ لا تُخلط مع الحدود البرية الافتراضية.
