## 1. Smart Boundary Extraction & Live Context UI
**تاريخ الاقتراح:** 9 أغسطس 2026

### 📝 وصف الفكرة:
إضافة خاصية تسمح للمستخدم بمعرفة اسم المنطقة التي ينظر إليها حالياً في الخريطة، مع إمكانية النقر على اسم المنطقة (سواء كانت دولة، مقاطعة، أو مدينة) ليقوم المحرك برسم حدودها الجغرافية بدقة كـ Shape Layer داخل After Effects.

### 🛠️ طرق التنفيذ المقترحة:

#### أ. شريط الموقع الذكي (Live Context Breadcrumbs)
- **كيف تعمل:** عند توقف الكاميرا عن التحريك، يتم إرسال إحداثيات مركز الخريطة إلى خدمة **Reverse Geocoding** (مثل Nominatim).
- **الواجهة:** يظهر شريط علوي أو سفلي يعرض التسلسل الهرمي للموقع (مثال: `Algeria > Algiers > Sidi M'Hamed`).
- **التفاعل:** كل اسم في الشريط هو عبارة عن زر. عند النقر عليه، يتم جلب ملف הـ GeoJSON الخاص بذلك النطاق ورسمه.

#### ب. البحث المتقدم (Smart Search Extract)
- **كيف تعمل:** عند البحث عن اسم منطقة في شريط البحث، لا تكتفي الإضافة بنقل الكاميرا، بل تُظهر زراً إضافياً (رسم الحدود).
- **التقنية:** إضافة البارامتر `polygon_geojson=1` لطلب الـ API الخاص بـ Nominatim. سيقوم الخادم بإرجاع إحداثيات الموقع (Center) بالإضافة إلى الشكل الهندسي الدقيق (Vector Polygon) الخاص بالحدود.

### ⚠️ التحديات التقنية (Technical Challenges):
- **تعقيد الـ Polygons:** بعض الدول أو المدن تمتلك حدوداً مفصلة بشكل جنوني تتكون من آلاف النقاط. إرسالها كما هي إلى After Effects قد يتسبب في تجميد البرنامج (Freeze).
- **الحل المقترح:** يجب بناء خوارزمية **تبسيط هندسي (Geometry Simplification)** (مثل خوارزمية *Douglas-Peucker*) داخل الـ JavaScript (أو الاستعانة بمكتبة مثل `simplify-js`) لتقليل عدد النقاط إلى مستوى معقول قبل تمريرها إلى سكربت الـ JSX الذي يرسم الـ Shape Layer.
