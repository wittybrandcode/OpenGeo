# OpenGeo — مصفوفة تحقق After Effects

تُنفّذ هذه المصفوفة على المصدر المثبت داخل CEP أثناء التطوير؛ ZXP مؤجل إلى مرحلة الإصدار. النتيجة الآلية الحالية: `npm test` = 109/109، وميزانيات الأداء الآلية ناجحة.

| ID | السيناريو | النتيجة المطلوبة | الحالة |
|---|---|---|---|
| AE-01 | إنشاء خريطتين في المشروع نفسه | compositions وassets مستقلة، ولا تحذف إحداهما الأخرى | ⬜ |
| AE-02 | سحب الخريطة 5 ثوان مع Live Sync | المزامنة مفعلة تلقائيًا؛ الموضع النهائي متطابق، ولا يتضخم Undo history | ⬜ |
| AE-12 | أضف keyframe، انتقل لزمن آخر، ثم حرّك الخريطة في اللوحة | عرض AE يتحرك فورًا عند الزمن الحالي؛ للخريطة المتحركة يُحدَّث/يُنشأ keyframe واحد لهذا الزمن | ⬜ |
| AE-13 | Finalize ثم انتقل لموقع بعيد | يظهر Preview للموقع الجديد؛ طبقات وأصول الـFinal لا تُحذف | ⬜ |
| AE-14 | فعّل Record ثم حرّك الخريطة في CTI مختلف | يظهر Preview الموقع الحالي ثم Preview للمسار؛ Keyframe واحد فقط لكل CTI | ⬜ |
| AE-15 | افتح اللوحة لأول مرة على شاشة عريضة ثم pan قرب ±180° | لا أشرطة سوداء جانبية؛ تتكرر البلاطات الملتفة بصريًا بلا تنزيلات مكررة | ⬜ |
| AE-16 | بدّل Satellite ↔ Vector Preview ثم نفّذ Finalize | Vector بلا شبكة/طلبات بلاطات؛ العودة تحمل الموقع الحالي؛ Finalize يبقى صوريًا | ⬜ |
| AE-03 | تحريك Camera من AE | تتحدث لوحة CEP دون feedback loop | ⬜ |
| AE-04 | تبديل active composition بين خريطتين | تستعاد camera/provider/الأبعاد الصحيحة | ⬜ |

| AE-08 | إغلاق/فتح اللوحة أثناء تنزيل أو stitch | لا تعديل لاحق غير مقصود ولا أخطاء معلقة | ⬜ |
| AE-09 | مشروع محفوظ ثم إعادة فتحه | metadata تستعيد camera/provider/الأبعاد وحالة finalize | ⬜ |
| AE-10 | provider يتطلب مفتاحًا من دون مفتاح | رسالة خطأ واضحة قبل أي download | ⬜ |
| AE-11 | مركز قريب من +179.9 و-179.9 | لا فراغات ولا طلب غير محدود للبلاطات | ⬜ |
| LS-01 | حرّك Panel ثم خلال أقل من ثانية حرّك Camera في AE | لا قفزة للخلف؛ لا تُسقط حركة AE الشرعية، ويتطابق الطرفان مع آخر حركة | ⬜ |
| LS-02 | دع AE غير مستجيب لثلاث دورات polling ثم أعده | حالة degraded واحدة بلا إزعاج، ثم recovery تلقائي؛ لا طلبات polling متداخلة | ⬜ |
| LS-03 | أضف Marker ثم انتظر اكتمال عدة tiles من دون تغيير الكاميرا | تتحدث المعاينة فقط؛ لا composition rebuild ولا Undo step جديد. استيراد GeoJSON أمر AE صريح ويُختبر في AE-39 | ⬜ |
| AE-34 | أعد تحميل اللوحة بعد CSP hardening، جرّب ESRI وOffline Vector والبحث ورسم بلد وSettings/attribution | لا شاشة فارغة أو CSP Console errors؛ الشبكة والworker والبيانات المحلية تعمل؛ attribution يفتح HTTPS فقط | ✅ 2026-08-14 |

| AE-39 | داخل Map composition ارفع GeoJSON فيه Polygon وLine وPoint، حرّك الخريطة ثم أعد رفع الملف نفسه | Canvas وAE متطابقان؛ Shape Layers تتبع MapPivot؛ الخط مفتوح والمضلع مغلق؛ لا طبقات مكررة بعد إعادة الرفع | ⬜ |
